# 寿命标签处理说明

## 题目要求理解

根据题目设计，附件中的 CSV 文件**不包含**直接的"循环寿命"字段，这是题目的设计而非数据缺失。参赛者需要：

1. **问题1/问题2**：基于 SOH 衰减趋势估计循环寿命（SOH 降至 80% 时的循环次数），并可用于辅助分析第 150/200 次循环的 SOH 值和衰减速率。
2. **问题3**：利用 9 块测试电池前 150 次循环数据预测 151~200 次 SOH 变化，再外推估计达到 80% SOH 时的寿命。精度通过测试数据评价，不要求事先知道真实寿命。

## 本方案处理方式

### 寿命估计（问题1）
- **外推方法**：对每块电池的 `SOH_smooth` 序列拟合线性模型 `SOH = a + k·N`，外推至 SOH=0.8 得到寿命 `L = (0.8 - a) / k`
- **辅助模型**：同时拟合指数模型 `SOH = exp(-λN + c)`，取两者中位数作为主寿命代理
- **辅助分析**（新增）：提取每块电池第 150/200 次循环的 SOH 值和衰减速率，作为策略间比较的直接指标
  - SOH@200 范围：0.9497~0.9975（无电池降至 0.8 以下）
  - 衰减速率范围：-21.0~-0.8（×1e5/循环）
  - 最快衰减：#35（3_7C-31PER-5_9C, -21×1e5），最慢：#2（3_6C-80PER, -0.8×1e5）

### 寿命不确定性（新增）
- **Bootstrap 置信区间**：对每块电池的 SOH 序列进行 2000 次 Bootstrap 重采样，拟合线性模型外推寿命，报告 95% CI
  - 示例：#16（3_7C-31PER-5_9C）寿命中位 1056，95%CI [1050, 1061]（窄区间，衰减快）
  - #2（3_6C-80PER）寿命中位 23958，95%CI [16045, 54115]（宽区间，衰减慢）

### 寿命作为因变量（问题2）
- 使用 P1 外推的寿命对数 `log(L)` 作为回归因变量
- 策略级（11 样本）与电池级（49 样本）R²_LOO 一致（0.445 vs 0.444），确认寿命估计方法稳健

### 寿命预测（问题3）
- 9 块测试电池前 150 次循环 → 递归预测 151~200 次 SOH → 合并真实+预测拟合直线外推至 0.8
- 精度由 40 块非测试电池留出验证评价（RMSE=0.00128，MAPE=0.109%）

### 优化中的寿命使用（问题4）
- 衰减斜率模型 `log|slope| = f(C1, Q1, C2, E_low, E_high, is_new)` 用于估计候选策略的衰减速率
- 寿命估计 `L = 0.2 / |slope|`，在已有实验参数范围内优化
